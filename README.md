# Disaster-Data-Analysis-in-Asia-2000-2024-Using-EM-DAT
This project analyzes disaster data in Asia from 2000 to 2023, using data from EM-DAT (International Disaster Database). It focuses on identifying trends in disaster types, affected countries, and the human/economic impact of disasters across Asia.
# Key Features
Data cleaning and handling of missing values
Filtering for Asian disaster events only
Exploratory data analysis.
Trends in disasters over time
Most frequent disaster types
Most affected countries by death toll and damages
Google Colab notebook for easy execution
